# IKEA — 더 나은 일상으로 가는 길

이케아 매장의 한 방향으로 이어지는 동선에서 영감을 받은 **비공식 학생 팀 프로젝트용 브랜드 경험 프로토타입**입니다.

쇼핑몰 전체를 구현하는 프로젝트가 아니라, 이케아의 역사·디자인 철학·플랫팩·생활 이야기를 스크롤로 소개하는 데모입니다.

## 집에서 바로 열기

이 저장소를 내려받고 **`index.html`을 크롬에서 열면 됩니다.** 별도 설치나 이미지 다운로드가 필요하지 않습니다.

Node.js가 설치되어 있다면 다음 명령으로도 실행할 수 있습니다.

```sh
npm start
```

브라우저에서 `http://localhost:3000`으로 접속하세요. 설치할 패키지는 없습니다.

검증 명령:

```sh
npm test
```

## 현재 구현

- **메인 히어로:** 1층부터 옥상까지 실내와 외곽을 연속해서 그리며 실내가 조금 앞서는 건물 애니메이션
- 건물 렌더 후 각각의 위치에서 자라는 식재, 완성 뒤 나타나는 헤더
- 코드로 그린 주변 도시 건물·도로·전차 선로·광장·보행자·가로수·벤치
- 제공된 IKEA 로고, Pretendard 폰트와 GO IKEA 버튼
- `compare.html`에서 히어로 A/B 비교 및 층별 도면 확인
- 9개 브랜드 이야기와 방향에 맞춘 가로·세로 화면 이동
- 직접 그린 파란선을 참고한 곡선 미니맵, 현재 위치 표시와 챕터 바로가기
- 프레임 시간에 따른 이동 완충과 부드러운 섹션 전환
- 섹션별로 다른 체류 시간
- **4번 섹션:** 한 자리에 머무는 스티키 3장면을 본 뒤 5번으로 이동
- **5번 섹션:** 부품별 테이블 분해·조립 체험
- **7번 섹션:** POÄNG·BILLY·KALLAX 소개와 공식 온라인몰 연결
- **8번 섹션:** 혼자 / 함께하는 겨울 분위기 선택
- 선택한 분위기의 카드 저장
- 큰 IKEA 로고로 마무리되는 푸터
- 모션 축소 설정 시 정적인 콘텐츠 제공

## 수정할 파일

**`index.html`이 최신 데모 진입점입니다.** 브랜드 여정은 이 파일에, 히어로의 CSS·JavaScript·이미지·폰트는 `assets/`에 있습니다. 팀원에게 전달할 때 저장소 전체를 내려받아 주세요.

히어로 수정: `assets/hero.js`, `assets/hero.css` / 드로잉 타이밍: `assets/interior-scene.js` / 주변 도시: `assets/city-scene.js` / 나무 성장: `assets/growing-render.js`.

| 위치 / 검색어 | 내용 |
| --- | --- |
| `const data=` | 브랜드 챕터의 제목과 문구 |
| `routeKnots` | 메인 화면이 이동하는 경로 |
| `minimapKnots` | 미니맵에만 사용하는 파란 곡선 |
| `holdDurations` | 각 섹션에 머무는 시간 |
| `stickyArtworks` | 4번 섹션의 세 장면 |
| `const products=` | 7번 섹션의 대표 제품과 공식몰 링크 |
| `footer-wordmark` | 큰 IKEA 로고 푸터 |

자세한 인수인계는 [PROJECT_NOTES.md](PROJECT_NOTES.md)를 참고하세요.

## 참고

- 시각 자료는 프로토타입용으로 단순화한 일러스트입니다. 실사 제품 이미지로 교체할 수 있습니다.
- 코드는 기하·타이밍·문법 검증을 통과했습니다. 실제 브라우저 FPS 측정과 최종 비주얼 QA는 추가로 필요합니다.
- IKEA 공식 프로젝트가 아닙니다. IKEA와 제품명은 해당 권리자의 상표입니다.

브랜드 내용은 IKEA 공식 역사와 Democratic Design 소개를 참고했으며, 상품 링크는 IKEA 대한민국 공식 온라인몰로 연결합니다.
